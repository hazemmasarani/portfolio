PERFORMANCE CASE STUDY

SSM–Gate Parallelism: Implementation and Evaluation

Multi-GPU inference · CUDA integration · Numerical validation

Back to Portfolio

Problem

Parallel state-space inference must balance GPU computation and communication while preserving numerical correctness. This project explores separating the state-space and gating paths and distributing their computation across GPUs.

Implementation

The design separates the SSM and gate paths into submodels and applies tensor parallelism within each. Related implementation work modifies existing CUDA and Triton code in a vLLM research fork.

Validation

Distributed outputs are compared with single-GPU references, including checks of intermediate activations. Evaluation considers latency, throughput, and correctness on NVIDIA A6000 and A100 GPUs.

Preliminary Findings

Under the evaluated configurations, the SSM–Gate approach showed an advantage over conventional tensor parallelism at small batch sizes. Results remain preliminary and depend on the workload and parallel configuration.
